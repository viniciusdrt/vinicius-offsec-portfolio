# Vinícius OffSec Portfolio

## Sobre o Projeto

Este repositório contém o **PortfolioHUB pessoal de Vinícius**, desenvolvido com foco em segurança ofensiva, pentest, automação e apresentação profissional de projetos técnicos.

O objetivo do PortfolioHUB é centralizar informações profissionais, habilidades, projetos, contatos e links importantes em uma única página publicada na web, utilizando o GitHub como ambiente de versionamento, organização e publicação.

Site publicado:
https://viniciusdrt.github.io/vinicius-offsec-portfolio/

## Objetivo do PortfolioHUB

O PortfolioHUB foi criado para funcionar como uma plataforma centralizada de apresentação profissional, reunindo:

* Perfil profissional;
* Habilidades técnicas;
* Projetos desenvolvidos;
* Repositórios no GitHub;
* Links de contato;
* Evidências de aprendizado e evolução na área de cibersegurança.

A implantação também teve como objetivo aplicar boas práticas de organização, documentação, controle de versão e segurança no uso do GitHub.

## Tecnologias Utilizadas

O projeto foi desenvolvido utilizando tecnologias simples e diretas para garantir leveza, compatibilidade e fácil manutenção:

* HTML5;
* CSS3;
* JavaScript;
* Git;
* GitHub;
* GitHub Pages;
* Google Gemini como ferramenta de apoio ao planejamento e revisão da implantação.

## Estrutura do Projeto

A estrutura principal do repositório é composta por:

* `index.html`: arquivo principal da página;
* `style.css`: arquivo de estilos visuais e responsividade;
* `script.js`: arquivo com comportamentos e interações da página;
* `README.md`: documentação principal do projeto.

## Projetos Apresentados

O PortfolioHUB apresenta projetos relacionados ao desenvolvimento técnico e à área de cibersegurança, incluindo estudos e ferramentas voltadas para programação, automação e segurança ofensiva.

Entre os projetos destacados estão:

Cada projeto funciona como evidência prática da evolução técnica e do desenvolvimento de habilidades aplicadas.

## Segurança e Boas Práticas

Durante a implantação, foram consideradas boas práticas básicas de segurança no uso do GitHub e na publicação do site.

As principais medidas adotadas foram:

* Não armazenar senhas, tokens ou chaves de API no repositório;
* Manter o repositório público apenas com informações adequadas para divulgação;
* Utilizar o GitHub Pages apenas para arquivos estáticos;
* Evitar exposição de dados pessoais sensíveis;
* Centralizar o controle de alterações por meio de commits;
* Manter a branch principal como versão estável do projeto.

## Como Executar Localmente

Para executar o projeto localmente, siga os passos abaixo:

1. Clone o repositório:

```bash
git clone https://github.com/viniciusdrt/vinicius-offsec-portfolio.git
```

2. Acesse a pasta do projeto:

```bash
cd vinicius-offsec-portfolio
```

3. Abra o arquivo `index.html` no navegador.

Como o projeto utiliza HTML, CSS e JavaScript puro, não é necessário instalar dependências adicionais.
